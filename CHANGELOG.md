# Changelog

## 0.1.0 — 2026-11-14

- SPF/DMARC validation with checkdmarc and RFC 9989 policy discovery.
- Separate SPF checks for subdomains.
- DKIM selector discovery and optional public selector archive.
- RSA/Ed25519 key inspection and revoked-key detection.
- DKIM verification for local .eml files.
- Markdown, CSV and JSON export.
- Windows CMD launcher and installable CLI.
- Offline regression tests and license notices.
